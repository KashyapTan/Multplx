Allow CLI and native delegation while keeping task-bound communication, queue ownership and truthful recovery.

Overview

The current delegation guard denies tools by name shape, while in-flight supervision depends on metadata that only Multplx spawn creates. Freedom requires removing that guard and making native session limits visible without turning registration into another permission gate.

Implementation steps

  1. Remove actual delegation fences.Remove the shape-based guard and tracked Cursor prohibitions. Audit generated launch settings and documented local deny lists. A no-op compatibility entry may serve old hooks for a defined transition period; no escape environment variable should be needed.
  2. Keep nested CLI mutation correctly scoped.Use the initiating task and parent identity for child launch and return routing. Reuse lock owners and atomic writers; never start a competing primary session in the parent home to append a report or create a child.
  3. Observe native children where supported.Use native lifecycle events or tool results to bind provider/session IDs to the existing task/session model. Report start, result and interruption through the same state owner. Never scrape arbitrary prose into authoritative completion facts.
  4. Handle unsupported observation honestly.Allow the native tool. Record session-bound delegation on the parent task with the available evidence and explain its recovery limitation. Do not invent a full backend, duplicate dashboard ledger, or native-resume guarantee.
  5. Preserve agent-to-agent communication.Route peers through validated recipient/home identity and task-scoped records; preserve correlation on retry. Internal messages carry task context and do not grant merge authority. Keep long results in artifacts with status pointers.
  6. Reconcile continuity.Retain singleton watcher locks, queue-before-notification ordering, canonical status reconciliation and AFK ownership transfer. Reconcile live independent children after parent restart; classify unavailable native work as interrupted, preserving artifacts for continuation.

  • Exercise actual supported Claude/Codex/Cursor/Pi native tool surfaces in isolated sessions. Missing provider hooks are a declared observation limit, not grounds for a delegation ban.

Documentation and instruction updates

Replace docs/subagent-guard.md with current delegation/observation behavior or retire it in favor of the architecture owner. Update harness references and dated evidence; keep service-process terms distinct from removed agent roles.

Definition of done

  • Available native delegation tools work without Multplx permission or an escape flag.
  • Both orchestrator and sub-agents can create further scoped work.
  • Canonical state accounts for supported native observations and declares unsupported recovery honestly.
  • Locks, wakes, status binding, AFK and correlated replies retain their meaningful guarantees.
Integration risk

Do not recreate the old guard as a mandatory tracking wrapper. Also do not call unobserved native children durable: preserving user freedom and reporting actual provider limits are both part of acceptance.
