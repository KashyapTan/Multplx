Lean Orchestration

Keep the coordination machinery. Give the agent freedom to do the work. Twelve implementation phases for one main orchestrator, scoped sub-orchestrators and their workers.

Accepted direction

The main orchestrator talks with the human, researches, plans and freely delegates. Implementer sub-agents code, commit, push branches and open PRs. The human performs PR merges. Selected workflows keep every step; deep-review and vplan run only when explicitly requested.

Read the porting guide for the complete design, source map, skill-by-skill disposition and migration rules. Phase 01 instruction scaffolding and Phase 02 task/project identity and lifecycle foundations are implemented and verified. Phase 03 implementation is in progress and remains planned pending final validation; local executable startup has recovered. Its evidence records the remaining checks; Phase 04 is not yet declared ready. Later phases remain planned. The product is not ready for release activation.

ORCHESTRATOROne user-facing agent focused on coordination, research and planning.
SUB-AGENTSResearcher, implementer and reviewer assignments in native or CLI sessions.
COORDINATIONFilesystem state, durable handling, current attempt identity and recovery.
HUMAN MERGESAgents deliver branches and PRs; people merge them.

Read the architecture assessment for source evidence and rationale. The user accepted its improvements; A1-A11 in the porting guide are required scope, including filesystem storage, durable handling, bounded observation, optional project discovery, one-chat multi-repo work, the TUI and the 1/5/10/20-task evaluation.

Standard orchestration

Launch multplx from any directory, optionally find repositories under configured roots, then ask the same orchestrator chat for feature A in repo 1, feature B in repo 2 and feature C in repo 3. Multi-task work across repositories is normal delegation, independent of launch location. The terminal home screen and MX Viz show all tasks; changing project context never redirects existing work.

Secondmate research informs Phase 05: optional domain coordinators delegate to workers and return durable outcomes to the same main chat.
