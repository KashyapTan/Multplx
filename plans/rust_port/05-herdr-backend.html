Overview

Herdr has the widest backend surface and the most recovery-sensitive presentation behavior.

This portion isolates that complexity from tmux and cmux so native events, projection journals, focus restoration, cleanup, and protocol compatibility receive dedicated proof.

Real backend evidence required

Mocks are necessary for fault matrices but insufficient for cutover. The required real-Herdr CI family must pass without a skip, and active verification must record the exact Herdr version and protocol.

Implementation steps

  1. Freeze the Herdr operation matrix.Capture every CLI call, JSON path, socket request, timeout, retry, label, protocol floor, and fallback branch.
  2. Port tool, version, session, and socket checks.Keep named-session scoping and never fall back to an unintended default session.
  3. Port basic workspace and pane operations.Implement ensure, create, ready, path, capture, composer, send, submit, native state, liveness, list, and verified kill.
  4. Replace both Python transports.Implement bounded AF_UNIX framing, subscription, JSON validation, flushing, timeout, cancellation, and the single allowed workspace-move request.
  5. Port presentation journals.Preserve tokens, home identity, parent workspace, exact endpoint binding, replacement, recovery, and stale-journal refusal.
  6. Port focus-safe projection lifecycle.Test create, reorder, close, restore, reclaim, rollback, seeded-tab prune, respawn, and flat fallback at every interruption point.
  7. Port lab and CI cleanup tools.Keep the default-session tripwire, exact lab prefix, pre-suite snapshot, and refusal to clean unowned sessions.
  8. Port the pinned installer.Preserve platform selection, checksum verification, version pin, protocol floor, destination mode, and consent boundary.
  9. Run the required real-Herdr gate.Keep the general backend default on legacy until Portion 06 completes cmux and dispatch.
