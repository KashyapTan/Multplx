Overview

This portion owns the transition from local work to an approved delivery handoff and the validated observation of remote PR state.

It must preserve credential separation, exact identity binding, non-executing migration, quarantine, crash recovery, and explicit merge authority.

Security review required

Treat every task ID, path, URL, SHA, branch, PR head, sidecar, registration, receipt, check result, and external command output as untrusted until it is validated and bound to the expected identity.

Implementation steps

  1. Port task, path, URL, and SHA validators first.Reject traversal, aliases, malformed providers, wrong hosts, abbreviated SHAs, non-regular files, link tricks, and mismatched metadata before any artifact opens.
  2. Port atomic PR artifact helpers.Preserve private modes, same-directory publication, content hashes, inode or identity binding where required, registration provenance, and receipt-backed retirement.
  3. Port static poll and canonical registration.Keep poll bytes static, sidecar data-only, provider validation, bounded official CLI calls, exact outputs, and no shell evaluation.
  4. Port the non-executing migration.Never execute, source, or parse legacy check programs as shell. Rebuild only from validated canonical metadata and quarantine everything ambiguous.
  5. Port deep review.Keep trusted default-branch config, fixed step order, structured findings, ask-user routing, restart evidence, command trust, exact rebase, and handoff publication.
  6. Port delivery records and credentialed execution.Revalidate SHA, branch, repo, remote, permissions, and handoff freshness immediately before push and PR creation.
  7. Port merges, promotion, diff review, and waiver.Preserve explicit maintainer authority, local fast-forward-only behavior, scout report retention, bounded review, and truthful waived status.
  8. Run adversarial and crash matrices.Exercise link swaps, file replacement, stale metadata, concurrent replacement polls, mid-retirement death, credential absence, and remote divergence.
  9. Cut over only after independent security review.Keep agents credential-free and test the credentialed service from its real external execution context.
