# Multplx generated portable test shards

The Rust `test-run` command owns the test inventory, resource manifest, scheduler, and CI lane composition.
The two portable accelerated lanes are generated by longest-processing-time assignment from `docs/mx-test-performance-baseline.json`.
Unknown or newly added scripts receive a conservative one-second estimate until a current accepted timing artifact replaces it.

## Lane topology

| Lane | Membership | Execution |
|---|---|---|
| `portable-parallel-1` | Generated half of portable scheduler pool | `--jobs auto` with resource conflicts |
| `portable-parallel-2` | Generated complementary half | `--jobs auto` with resource conflicts |
| `portable-serial` | `global` and live-harness opt-in owners | Same scheduler, where `global` overlaps nothing |
| `real-herdr-gated` | Real Herdr family | Dedicated owned lab lane, serial |

The portable scheduler pool excludes the real-Herdr family, live-harness owners, and global self-contracts.
The resource scheduler may overlap disjoint scripts inside either generated shard.
Scripts sharing `herdr-session`, `tmux-server`, `watcher-process`, `process-signal`, `cmux-app`, or another declared resource never overlap.

## Generation

The runner loads per-script `duration_ms` from `docs/mx-test-performance-baseline.json`.
The accepted baseline also carries `scheduler_estimates_ms` for replacement scripts created by suite splitting.
Scripts are sorted by descending estimate and assigned to the currently lighter of two bins.
Path order breaks equal-duration ties deterministically.

Inspect the current result with:

```sh
target/release/mx test-run --list --lane portable-parallel-1
target/release/mx test-run --list --lane portable-parallel-2
```

Do not maintain a second hand-written shard list.

## Coverage guard

`target/release/mx test-run --check-coverage` proves all of the following:

1. Every `tests/*.test.sh` path has exactly one explicit resource declaration.
2. The two generated accelerated shards are disjoint and equal the portable scheduler pool.
3. The accelerated shards, global/live remainder, and real-Herdr family are pairwise disjoint.
4. Their union equals the complete inventory exactly once.

CI runs this guard before behavior jobs.

## Timing artifacts

Every lane writes the same runner JSON shape with exits, gate skips, resources, named assertion multisets, and durations.
The aggregate CI job combines lane artifacts through `target/release/mx test-run --aggregate-json`.
Serial and accelerated artifacts compare through `target/release/mx test-run --compare-json`.
The performance owner and accepted run history are in [mx-test-performance.md](mx-test-performance.md).

## Hang tripwires

CI timeouts are failure tripwires rather than expected healthy durations.
The portable accelerated jobs retain a fifteen-minute tripwire.
The global/live remainder retains a twenty-minute tripwire until three green main-branch measurements justify lowering it.
The dedicated real-Herdr lane retains its forty-minute tripwire.
Tripwire adjustments do not replace performance fixes; retries, new skips, and reduced fault matrices are not acceptable performance strategies.
